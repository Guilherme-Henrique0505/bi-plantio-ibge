# Análise de Produção Agrícola: Sorriso (MT) - Dados IBGE

Este projeto de Business Intelligence apresenta uma análise detalhada sobre os dados de plantio e produção agrícola da cidade de Sorriso, no Mato Grosso, utilizando dados oficiais disponibilizados pelo IBGE. O objetivo foi consolidar informações de safras e culturas em um painel que facilite a compreensão do desempenho agrícola da região.

## Funcionalidades e Escopo do Projeto

O relatório foca na clareza dos indicadores de produção e na eficiência da leitura dos dados setoriais:

* **Análise de Culturas:** Visualização da distribuição de área plantada e volume de produção por tipo de cultura.
* **Indicadores de Desempenho:** Monitoramento de rendimento médio e área colhida para identificação de tendências de produtividade em Sorriso.
* **Padronização Visual:** O projeto passou por uma atualização completa de layout para garantir uma interface profissional e coerente com as melhores práticas de UX.

## Estrutura Técnica e Engenharia

O projeto foi estruturado para atender aos padrões de desenvolvimento moderno, permitindo maior transparência e controle sobre o modelo:

* **Arquitetura PBIP e TMDL:** O modelo de dados foi convertido para o formato de projeto do Power BI, utilizando TMDL para a definição de medidas e relacionamentos. Essa estrutura permite que o arquivo seja gerenciado como código fonte.
* **Versionamento via Git:** Todo o ciclo de desenvolvimento e atualização visual foi registrado no GitHub, utilizando um histórico de commits organizado para rastrear a evolução do projeto.
* **Modelagem de Dados:** Tratamento e estruturação das tabelas originais do IBGE para garantir performance nos visuais e precisão nos cálculos de inteligência temporal.

## Estrutura do Repositório

* **/dataset:** Definições das fontes de dados, metadados e lógica de medidas em TMDL.
* **/report:** Configurações de layout, temas e organização dos visuais do relatório.
